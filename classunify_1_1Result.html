Detailed Description

template<typename T_SuccessType = unify::Success, typename T_Failure = unify::Failure>
class unify::Result< T_SuccessType, T_Failure >

A templated class meant to convey either a success or a failure via defined types. Defaults to either lite weight Success or Failure class.

Note
It is important to know that this result is about half (per GTest) as efficient as returning a simple POD (bool or int). It should be avoided in high performance code where special return values, or mechanisms as mention above.
